# PWAs

A couple of small Progressive Web Apps I've built — installable and offline-capable, packaged with a manifest and service worker — plus a standalone utility script.

## apps/CollageGen

A photo collage generator. Python backend for image processing, with an HTML/CSS/JS frontend wired up as an installable PWA.

## apps/BoomRandom

A random content picker, also packaged as a PWA.

## IconCreator.py

A standalone script for generating the icon sets a PWA needs (multiple sizes/formats for `manifest.json`).
